# Flaffybird

A roguelike Flappy Bird — one self-contained HTML file, no dependencies.

- Tap/click/space to flap. Every 5 points: pick 1 of 3 upgrades (pool of 9).
- At 50: snake ambush — armed snakes on pipes, 10 HP, katana parries, gold per kill.
- Gold persists and buys permanent shop upgrades. Settings lets you move the PARRY button.

Play: open `index.html`, or the hosted page via GitHub Pages.
